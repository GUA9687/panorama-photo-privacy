# 详细使用说明

## 1. 导入与缓存

输入要求是约 2:1 的等距柱状全景、8 位 RGB JPG/JPEG，EXIF Orientation 为标准方向 1。队列接受一个或多个本地文件，也可通过已挂载的 NAS 路径读取；网络路径性能取决于局域网和存储。

把照片拖到“添加照片”下方的队列，或者使用文件选择窗口。目录不会递归扫描，重复路径会跳过。正在执行前台长任务时暂停添加和切换。

大 JPEG 首次打开会解码为磁盘上的原生 `.v` 缓存，以免每次查看人脸都从 JPEG 开头重新解码。50,698×25,349 的 RGB 原生数据约 3.86 GB，另需预览和导出空间。队列不会一次性把所有原片放进内存；每张照片的候选和样式分别保存。

## 2. 查找与检查候选

默认选择“明显人脸”；“更多候选”降低门槛，增加需要人工判断的区域。处理状态会显示设备、校准、扫描及人物环境筛选。

右侧默认隐藏被判断为背景的自动候选。“显示疑似背景候选”可把它们找回；这些区域仍保存在项目中。手动区域始终显示。模型或筛选步骤不可用时会明确提示，并保留候选供检查。

列表模式提供解释；缩略图网格只显示图片和复选框，悬停可看说明。拖动中间与右侧的分隔条调整网格列数。双击候选或按“定位”可查看对应位置。拖动画面改变视角，滚轮缩放；停止操作后读取原图高清区域。

候选缩略图显示上下文，便于判断是否为人；实际遮挡范围以主画面的遮挡预览为准。可取消“遮挡预览”查看原片。遗漏区域可通过“手动框选”补充。

## 3. Windows 式批量选择

| 操作 | 效果 |
|---|---|
| 普通点击候选 | 选中当前候选 |
| Ctrl + 点击 | 增加或取消这个候选的选择 |
| Shift + 点击 | 从当前选择锚点连续选择 |
| 空白处拖框 | 框选多个候选，尤其适合网格 |
| 勾选所选 / 取消所选 | 统一启用或关闭选中区域的遮挡 |
| 空格 | 按当前候选勾选状态，统一切换所选区域 |
| 点击已选候选的复选框 | 将这一组选中项改为同一勾选状态 |
| 点击未选候选的复选框 | 仅操作该候选 |
| Ctrl + Z | 撤销上一步区域编辑；批量操作只需撤销一次 |

高亮表示选中，打勾表示参与导出。选择本身不会改变遮挡。隐藏候选不参加批量操作；如果某个启用的背景候选随后被隐藏，界面会提示隐藏项仍参与遮挡。刷新缩略图、切换列表/网格和撤销时按区域 ID 保持选择。“移除当前”只移除当前候选。

## 4. 遮挡样式

新照片默认椭圆、强高斯模糊和每侧 25% 外扩。25% 外扩使宽高各扩大到原脸框的 1.5 倍，椭圆通常可以覆盖原始矩形脸框四角。减小外扩后应检查边缘。圆形按记录视角中的像素尺度定义；球面投影在展开图中可能呈曲线。

可选强模糊、马赛克、实色。实色不是透明覆盖。不同形状共享球面遮罩，预览与导出使用同一判断规则；不同分辨率下的插值及 JPEG 编码仍可能带来显示差异。

旧项目缺少新样式字段时保留矩形和原来的高质量重编码行为。可以手动切换到椭圆和自动局部导出。

## 5. 导出

默认“自动：优先局部处理”。支持的 8 位基线 RGB/YCbCr JPEG（4:4:4 或 4:2:0）在内存足够时使用局部 DCT 系数修改。保留原量化表，不使用 95/98/100 选项重新设定局部编码质量。

整图重编码和自动回退使用选择的质量 95、98 或 100，采用 4:4:4。默认 98。质量越高通常文件越大，100 仍不等于无损。

输出必须使用新文件名；不会覆盖原片或现有输出。完成前会进行验证，失败或取消不发布半成品。取消可能等待已启动的小任务安全结束。

EXIF 含缩略图或不透明 MakerNote 时会回退并清除 EXIF，界面会说明；ICC/XMP/IPTC 在可安全处理的情况下继续保留。含额外图像、扩展 XMP 或无法安全检查的预览载荷时，本版本会停止导出并提示处理元数据。不能通过切换重编码绕过这个检查。

## 6. 保存项目与换机

项目 JSON 保存区域、样式、原片路径及缓存信息，不包含原始照片。使用“保存项目”保存；换机时同时准备原片。原片不存在或指纹发生变化时需重新关联，尺寸必须一致。不要把另一张照片关联到旧区域。

迁移软件：复制完整便携文件夹或下载 ZIP 解压。无须复制旧电脑的 Python 环境。缓存和日志位于 `%LOCALAPPDATA%/PanoramaPrivacy/` 下；移动原片或清理缓存前先保存项目，并确保没有正在执行的任务。

## 7. 常见问题

- **没有 GPU 加速**：查看状态是否为 CPU；确认 NVIDIA 驱动支持包内 CUDA 运行库。CPU 回退仍可用，但速度不同。
- **内存或磁盘不足**：腾出缓存/输出空间，关闭其他大内存应用，或选择流式高质量重编码；降低 JPEG 质量主要减少输出大小，不会减少原始 RGB 缓存尺寸。
- **把雕像当成人**：取消候选勾选。人物上下文筛选降低误报，不能证明被摄对象一定是真人。
- **只复制 EXE 无法启动**：重新完整解压软件包，保持 `_internal` 目录。
- **导出验证失败**：查看提示和 `%LOCALAPPDATA%/PanoramaPrivacy/Logs/application.log`；不要把未验证临时文件作为完成输出。
