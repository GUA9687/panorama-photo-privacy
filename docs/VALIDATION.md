# 验证记录与限制

以下为0.2.0在Windows11、RTX5080 Laptop16GB和约64GB RAM上的本机记录，测试原片及私人工作文件不随仓库发布。

| 验证 | 结果 |
|---|---|
| 新公开仓库照片专项测试 | 从便携包补齐模型/runtime后，使用原已验证Python环境运行，125项通过（16.25秒） |
| 原开发环境完整回归 | 228项通过；含共享视频回归 |
| 便携EXE CPU和CUDA自检 | 均通过，使用精简PATH和不同工作目录 |
| 156个冻结A/B裁剪，ONNX对原型 | CPU和CUDA判定差异均为0 |
| 原生缓存的78候选筛选 | 29可见，其中26个人物全部保留，仍3背景误报 |
| 低内存视图对照 | 8个场景RGB逐像素一致 |
| 50,698×25,349完整扫描 | 100.44秒，包括9.35秒校准、YuNet和上下文；6818块 |
| 本次并行选择 | 1/2/4路46.7/67.3/83.3块每秒，选择4路；8路未通过资源预算 |
| 扫描一致性 | 17提案几何/分数/复核原因与基线相同；16可见、10启用 |
| 完整扫描资源 | 进程峰值RSS约9.92GB，最低系统可用RAM约29.73GB |
| 同一大图椭圆局部JPEG导出 | 52.27秒，10个启用区域，437个受影响MCU |
| 局部JPEG验证 | 原量化表/采样/APP/COM保留；未修改系数一致，允许影响范围外像素差异0；原片SHA不变 |
| UI | 实际Qt拖放、Ctrl/Shift、网格框选、批量勾选、空格、一步撤销、状态恢复等事件验证 |

上下文阈值是在这组候选上调整的，因此29/26/3是样本内结果，不是未知场景准确率。模型会受服饰、遮挡、雕像、图案、拍摄角度和分辨率影响。

性能数值包含不同阶段，不能把局部编码时间、带完整验证的导出时间和单纯模型推理时间直接比较。本机记录不是所有显卡的保证；程序按资源和实际吞吐选择并发，不承诺GPU使用率100%。

本版本未在4080上实机验收，也未验证所有JPEG编码器/元数据变体。已测试奇数尺寸444/420、接缝、圆形/椭圆、重叠、Unicode路径、取消、低内存回退、损坏输入、量化表不匹配、验证失败和元数据预览载荷。

可执行文件未声明代码签名。程序的complete/validated表示处理与结构检查成功，不是人脸覆盖完整性的保证。
