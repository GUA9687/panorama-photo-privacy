# Panorama Photo Privacy · 全景照片人脸遮挡

面向 Windows 的本地全景照片人脸检查与遮挡工具。针对约 2:1 的等距柱状全景 JPEG，自动提出人脸候选，结合人物上下文减少背景误报，由使用者检查后导出。当前发布版本 **0.2.0**，中文界面。

## 下载与开始使用

**[下载 Windows 便携版](https://github.com/GUA9687/panorama-photo-privacy/releases/tag/v0.2.0)**

1. 下载 `PanoramaPhoto-Windows-0.2.0.zip`，完整解压到可写目录。
2. 双击 `PanoramaPhoto.exe`。保留同目录 `_internal` 等文件，不能只复制 EXE。
3. 点击“添加照片”，或把 JPG/JPEG 拖入照片队列。
4. 点击“查找人脸”，检查右侧候选，勾选需要遮挡的区域。
5. 选择形状、遮挡方式及导出方式，导出到一个新的 JPG 文件。

程序运行时不上传照片，也不需要在线模型服务；模型、图片运行库和 CUDA 用户态运行库随便携包提供。显卡驱动由电脑自身提供。Release 压缩包约 1.57 GB，解压内容约 2.35 GB，不包含测试照片。

## 功能

- 单张或多张照片拖拽导入，重复路径跳过；队列按当前照片准备缓存。
- 原生分辨率人脸扫描，以及球面透视补充检测；保留可恢复的疑似背景候选。
- 列表和无文字缩略图网格，网格随侧栏宽度重排；双击定位。
- Ctrl 增减选择、Shift 连续选择、空白处拖框、空格切换勾选、批量勾选/取消、一步撤销。
- 默认强高斯模糊、椭圆、每侧外扩 25%；另有马赛克、实色、圆形和矩形。
- 根据可用 RAM/VRAM 和实测吞吐选择 GPU 并行数；支持可见的 CPU 回退。
- 支持 JPEG 局部系数修改；不适用时使用高质量重编码，质量可选 95/98/100。
- 保存/恢复项目，源文件变更检查，任务取消，临时文件验证和原子发布。

## 环境概览

已在 **Windows 11 x64、RTX 5080 Laptop 16 GB、约 64 GB RAM** 上完成测试。GPU 运行环境使用 ONNX Runtime GPU 1.31、CUDA 13 用户态 DLL 与 cuDNN 9。本发布未在 RTX 4080 上实机验收；换机后会重新评估资源，驱动不兼容时可能回退 CPU。

50k 全景照片的缓存与导出需要数 GB 临时磁盘空间。32 GB RAM 可作为大图使用的建议起点，64 GB 更宽裕；这不是经所有机器验证的硬性最低配置。内存不足时局部 JPEG 会回退到流式重编码。

## 重要边界

自动检测提供待检查候选，不保证全部找到或全部正确。雕像、衣物图案等仍可能误报；远处、遮挡或模糊的人脸可能漏检。使用者应在发布照片前检查结果。

局部 JPEG 保留**未触及编码块**的系数；遮罩触及的块会重新编码，所以并非所有遮罩外像素都保证不变。质量 100 的整图 JPEG 重编码也不是无损导出。

当前照片工具不支持全景切片目录、非 2:1 图像、RAW、透明图、CMYK 或高位深素材。源码保留与早期视频工具共享的模块，但本仓库当前 Release 仅交付照片 EXE，视频功能不属于本版本使用说明或验收范围。
